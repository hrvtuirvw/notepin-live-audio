# 検証範囲

## 既存の所有者実機で確認したこと

初代PLAUD NotePinとAndroid端末で、所有者認証、録音データの取得・復号、WAV保存・5音声分分割、任意のPC転送の受信ACKを観測しました。録音中の「取得済み位置」通知で接続を終了せず、次の音声を待つ修正を含みます。

別のPC／BLE検証でも、録音を継続したまま20.64秒分の音声を取得・復号しました。一方、録音中の一覧要求は2回の12秒待機で応答しませんでした。全件列挙・分割一覧の実機動作を確認したという意味ではありません。

## この公開版での変更

- Androidの一覧処理を、認証のprotocol version・要求UID・総件数・ページ開始位置に基づく方式へ変更。ページ再送、欠落、重複、未応答を区別します。
- Linuxの過去ID指定を、機器が録音していない状態でも選択できるよう修正。
- READMEを現在録音の取得と過去録音の回収に絞り、FW／隠し機能／クラウドAPI棚卸しを公開ツリーから分離。
- 第三者ライセンスを保持。

この準備では実機を接続・操作していません。修正版の実機動作は未検証です。
