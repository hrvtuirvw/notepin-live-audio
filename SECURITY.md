# Private data

Do not include private keys, bootstrap JSON, access tokens, cookies, HCI captures, device/account identifiers, recordings, SQLite inboxes, or real transcripts in issues or pull requests. Use synthetic fixtures and redacted error messages.

Android protects imported bootstrap values with a Keystore-backed vault, but plaintext import files and exported WAVs remain the operator's responsibility. The receiver contains decrypted private audio. Keep its storage private and use trusted TLS with bearer authentication.

This is an experimental owner-device interoperability tool, not an authentication bypass or general-purpose account login client. No start/stop/delete/unbind/update commands are provided.

No dedicated vulnerability reporting channel has been configured yet. Do not disclose exploit details or credentials in a public issue; use a repository owner's private contact once one is established.
